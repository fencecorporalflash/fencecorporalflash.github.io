Что такое Windows Mobile и чем эта система отличается от Windows Phone

Обновлено 24 сентября 2026 г.
📋 Содержание
  • Что такое Windows Mobile: определение и назначение

Запрос «вин мобайл» чаще всего означает Windows Mobile — мобильную операционную систему компании Microsoft, которая устанавливалась на смартфоны и КПК в 2000-х годах. Если вы нашли старый коммуникатор с логотипом Windows, столкнулись с упоминанием этой ОС в инструкции к терминалу сбора данных или пытаетесь запустить программу, написанную под неё, — важно сначала понять, о какой именно платформе идёт речь, потому что под похожими названиями скрываются разные системы.

Путаница возникает из-за того, что Microsoft выпускала несколько поколений мобильных ОС под похожими именами: Windows Mobile, Windows Phone и Windows 10 Mobile — это три разные платформы с несовместимыми приложениями. Разберёмся, что представляет собой каждая из них, на каких устройствах они работали и имеет ли смысл использовать их сегодня.

Что такое Windows Mobile: определение и назначение

Windows Mobile — это семейство операционных систем Microsoft для портативных устройств, основанное на ядре Windows CE. Система вышла в начале 2000-х годов и стала развитием платформы Pocket PC. Её главная идея — перенести привычный интерфейс настольной Windows на экран карманного компьютера: меню «Пуск», проводник, офисные приложения.

Платформа выпускалась в нескольких редакциях под разные классы устройств. Версии различались по наличию телефонного модуля и сенсорного экрана, поэтому приложения, написанные под одну редакцию, не всегда корректно работали на другой.

  • 📱 Windows Mobile Standard — для смартфонов без сенсорного экрана, с управлением кнопками;
  • 📟 Windows Mobile Professional — для КПК и коммуникаторов с сенсорным дисплеем;
  • 🖥️ Windows Mobile Classic — для карманных ПК без функции телефонии.

Последней крупной версией стала Windows Mobile 6.5, выпущенная в 2009 году. После этого Microsoft полностью переработала платформу и представила Windows Phone 7, которая не имела обратной совместимости со старыми приложениями.

Чем Windows Mobile отличается от Windows Phone

Это принципиально разные системы, и их часто путают. Windows Phone — полностью новая платформа 2010 года с интерфейсом из «плиток» (Metro/Modern UI), ориентированная на массового потребителя. Она не умеет запускать программы, написанные для классической Windows Mobile.

Проверить, какая система стоит на конкретном устройстве, можно по внешним признакам: у Windows Mobile интерфейс напоминает уменьшенную десктопную Windows с меню «Пуск» в углу экрана и стилусом в комплекте, у Windows Phone — крупные цветные плитки и управление пальцами без стилуса.

КритерийWindows MobileWindows Phone
Годы актуальности2000–20092010–2017
Ядро системыWindows CEWindows CE, затем Windows NT
ИнтерфейсКлассический, как на ПКПлиточный (Metro)
УправлениеСтилус, резистивный экранПальцы, ёмкостный экран
Совместимость приложенийТолько между своими версиямиНесовместима с Windows Mobile
💡

Windows Mobile и Windows Phone — несовместимые платформы: приложения одной системы не запускаются на другой, несмотря на похожие названия.
