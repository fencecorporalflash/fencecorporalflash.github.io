Переустановка Windows на планшете Prestigio Visconte S

Обновлено 24 сентября 2026 г.

Планшет Prestigio Visconte S поставлялся с предустановленной Windows 8.1 with Bing на платформе Intel Bay Trail, и именно эта связка определяет главные сложности переустановки: 32-битный загрузчик UEFI при 64-битном процессоре, ограниченный объём встроенной памяти eMMC и отсутствие полноразмерного USB-порта. Из-за этого обычная загрузочная флешка, созданная «как для ноутбука», часто просто не определяется планшетом.

В этой инструкции разберём, как подготовить установочный носитель именно под Visconte S, какие драйверы понадобятся после чистой установки и что делать, если планшет не видит флешку или зависает на этапе установки. Материал ориентирован на чистую переустановку с сохранением лицензии, а не на обновление поверх существующей системы.

Что нужно знать перед переустановкой

Главная особенность Visconte S — 32-битный UEFI (загрузчик) в сочетании с 64-битным процессором Intel Atom. Это значит, что установочный образ Windows должен содержать файл загрузчика bootia32.efi, иначе планшет физически не сможет стартовать с флешки. Официальные 64-битные образы Windows 8.1 и 10 его не содержат — только 32-битные редакции.

Второй момент — лицензия. Ключ продукта зашит в UEFI планшета, поэтому при установке той же редакции (Windows 8.1 with Bing / CoreSingleLanguage) активация произойдёт автоматически после подключения к интернету. Вводить ключ вручную не потребуется — установщик подхватит его сам.

Третий нюанс — память. Встроенного накопителя eMMC хватает впритык, поэтому перед установкой стоит удалить всё лишнее, а личные файлы перенести на карту microSD или в облако. Чистая установка удалит все данные с внутреннего накопителя, включая раздел восстановления, если вы отформатируете диск полностью.

Что понадобится для установки

Соберите комплект заранее — искать переходник в середине процесса будет поздно. Планшет имеет только порт micro-USB, поэтому без OTG-переходника подключить флешку не выйдет.

  • 🔌 USB-OTG кабель или переходник micro-USB → USB-A для подключения флешки и клавиатуры
  • 💾 Флешка от 4 ГБ для 32-битного образа Windows
  • ⌨️ USB-клавиатура (или USB-хаб) — сенсорный ввод в установщике может не работать без драйверов тачскрина
  • 🔋 Заряженный аккумулятор и подключённое зарядное устройство на весь процесс
  • 💻 Второй компьютер с Windows для создания загрузочной флешки

⚠️ Внимание: одновременно заряжать планшет и использовать OTG через единственный micro-USB порт стандартными средствами нельзя. Если заряд батареи низкий, сначала полностью зарядите устройство — прерывание установки из-за разрядки может оставить планшет без рабочей системы.

Создание загрузочной флешки для 32-битного UEFI

Это самый ответственный этап. Скачайте 32-битный (x86) образ Windows 8.1 с официального сайта Microsoft — средство Media Creation Tool позволяет выбрать разрядность при загрузке. Записать образ на флешку можно через Rufus или вручную.

В Rufus выберите схему раздела GPT и целевую систему UEFI (non-CSM), файловую систему — FAT32. Именно FAT32 обязателен: UEFI-прошивка планшета не загружается с NTFS-носителей.

Если Rufus недоступен, флешку можно подготовить вручную через командную строку:

diskpart

list disk

select disk N

clean

convert gpt

create partition primary

format fs=fat32 quick

assign

exit

После этого просто скопируйте содержимое ISO-образа на флешку. Проверьте, что в папке efi\boot присутствует файл bootia32.efi — без него планшет не увидит носитель как загрузочный.

💡

Если bootia32.efi отсутствует в образе, скопируйте его из установленной 32-битной Windows с другого ПК: файл находится в папке C:\Windows\Boot\EFI или извлекается из install.wim.
