Windows 98: год выпуска и история легендарной операционной системы

Обновлено 24 сентября 2026 г.

Windows 98 была официально выпущена 25 июня 1998 года компанией Microsoft — именно эта дата считается точкой релиза розничной версии системы, а кодовое имя проекта на этапе разработки звучало как Memphis. Название операционной системы прямо указывает на год выхода, что было фирменным подходом Microsoft в ту эпоху: так же маркировались Windows 95 и позднее Windows 2000.

Система стала развитием линейки Windows 9x, построенной на гибридном ядре с элементами MS-DOS. Она пришла на смену Windows 95 и быстро заняла доминирующее положение на рынке домашних компьютеров конца 1990-х. Для многих пользователей именно Windows 98 стала первой операционной системой, с которой началось их знакомство с персональным компьютером.

Даты выпуска: первая и вторая редакции

Линейка Windows 98 включала два основных релиза. Оригинальная версия, известная как Windows 98 First Edition, поступила в продажу в июне 1998 года. Спустя примерно год, в мае 1999 года, вышла обновлённая редакция — Windows 98 Second Edition (сокращённо SE), которая включала исправления ошибок, обновлённый браузер Internet Explorer 5 и улучшенную поддержку сетевых технологий.

Различить редакции можно в свойствах системы: вторая редакция помечалась соответствующей надписью в окне сведений о системе. Именно SE считается наиболее стабильной и оттого наиболее популярной среди энтузиастов ретро-компьютеров и по сей день.

  • 📅 25 июня 1998 года — релиз оригинальной Windows 98 (First Edition)
  • 📅 Май 1999 года — выход Windows 98 Second Edition
  • 📅 2000 год — появление Windows ME, заключительной системы линейки 9x
  • 📅 Июль 2006 года — полное прекращение расширенной поддержки Windows 98 со стороны Microsoft
