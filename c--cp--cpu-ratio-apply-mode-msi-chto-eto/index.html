CPU Ratio Apply Mode в BIOS MSI: что это за параметр и как его настроить

Обновлено 24 сентября 2026 г.
📋 Содержание
  • Что такое CPU Ratio Apply Mode простыми словами
  • Основные режимы: All Core, Per Core и Turbo Ratio

Открыв раздел OC в BIOS материнской платы MSI, многие пользователи замечают строку CPU Ratio Apply Mode и не понимают, какое значение выбрать — от этого параметра напрямую зависит, как именно процессор применит множитель частоты: ко всем ядрам сразу или к каждому по отдельности. Неверный выбор режима может привести к тому, что разгон не заработает, система станет нестабильной или процессор будет перегреваться под нагрузкой.

В этой статье разберём, что означает CPU Ratio Apply Mode, какие варианты предлагает BIOS плат MSI, чем они отличаются на практике и какой режим выбрать для ручного разгона или повседневной работы.

Что такое CPU Ratio Apply Mode простыми словами

Частота процессора формируется как произведение базовой частоты шины (BCLK, обычно 100 МГц) на множитель — CPU Ratio. Например, множитель 50 при базовой частоте 100 МГц даёт итоговые 5,0 ГГц. Параметр CPU Ratio Apply Mode определяет способ применения этого множителя к ядрам процессора.

Проще говоря, BIOS спрашивает у вас: задать один множитель для всех ядер сразу или настроить каждое ядро (либо группу ядер) индивидуально? От ответа зависит гибкость разгона и то, как процессор будет вести себя в многопоточных и однопоточных задачах.

Точный набор доступных режимов зависит от конкретной модели платы, чипсета и поколения процессора. Названия пунктов и их расположение могут отличаться, поэтому сверяйтесь с руководством к вашей плате на официальном сайте MSI.

Основные режимы: All Core, Per Core и Turbo Ratio

В BIOS плат MSI для совместимых процессоров Intel чаще всего встречаются три варианта применения множителя:

  • 🔧 All Core — единый множитель применяется ко всем ядрам одновременно. Классический вариант для стационарного разгона: все ядра работают на одной фиксированной частоте.
  • ⚙️ Per Core — множитель задаётся индивидуально для каждого ядра. Позволяет разогнать сильные ядра выше, а слабые оставить на умеренной частоте.
  • 🚀 Turbo Ratio — множитель настраивается в зависимости от количества активных ядер: при нагрузке на 1–2 ядра частота выше, при полной загрузке — ниже. Похоже на логику штатного Turbo Boost, но с ручными значениями.

Пункт CPU Ratio Apply Mode появляется в меню OC → Advanced CPU Configuration (путь может отличаться) и активен, когда включён ручной режим задания множителя. Если множитель оставлен в Auto, выбор режима ни на что не повлияет.
