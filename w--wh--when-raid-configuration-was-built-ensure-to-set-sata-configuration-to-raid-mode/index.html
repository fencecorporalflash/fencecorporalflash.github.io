When RAID configuration was built: зачем переключать SATA Configuration в режим RAID

Обновлено 24 сентября 2026 г.
📋 Содержание
  • Что означает режим RAID в настройках SATA
  • Признаки того, что режим SATA выбран неверно

Сообщение вида «when RAID configuration was built ensure to set SATA configuration to RAID mode» появляется в утилитах настройки BIOS/UEFI как напоминание: если вы планируете собрать RAID-массив из дисков, контроллер SATA должен работать именно в режиме RAID, а не AHCI или IDE. Пока переключатель стоит в другом положении, прошивка платы просто не предоставит интерфейс для создания массива, а уже собранный том может перестать определяться.

Проблема чаще всего всплывает в двух сценариях: при первой сборке массива на новой плате и после сброса BIOS к заводским настройкам, когда режим SATA «откатывается» на AHCI. Во втором случае система с RAID перестаёт загружаться, и пользователь видит либо ошибку загрузчика, либо отсутствие дисков в установщике ОС. Ниже разберём, как работает переключение режимов, какие признаки указывают на неверную настройку и как выполнить переключение без потери данных.

Что означает режим RAID в настройках SATA

Параметр SATA Mode (он же SATA Configuration, SATA Operation, Storage Mode — название зависит от производителя платы) определяет, как чипсет представляет подключённые накопители системе. В режиме AHCI каждый диск работает автономно через стандартный драйвер. В режиме RAID активируется встроенный контроллер массивов — например, Intel Rapid Storage Technology или AMD RAIDXpert2, — и появляется возможность объединять диски в RAID 0, 1, 5, 10.

Важно понимать: само по себе переключение в RAID не создаёт массив. Это лишь включает «прослойку» контроллера, после чего в BIOS или в отдельной утилите (вызываемой горячей клавишей при загрузке либо из раздела настроек UEFI) появляется меню конфигурации томов. Именно поэтому предупреждение формулируется как «ensure to set SATA configuration to RAID mode» — это предварительное условие, а не само действие по сборке.

  • 🔧 RAID 0 — чередование данных для скорости, без отказоустойчивости.
  • 🛡️ RAID 1 — зеркалирование, данные дублируются на оба диска.
  • ⚖️ RAID 5/10 — комбинации скорости и избыточности, требуют больше дисков.
  • 💾 AHCI — режим по умолчанию для одиночных дисков, без массивов.

Признаки того, что режим SATA выбран неверно

Короткая диагностическая проверка: зайдите в BIOS и посмотрите, видны ли диски в разделе конфигурации RAID-контроллера. Если раздела нет вообще — почти наверняка SATA работает в AHCI, и контроллер массивов отключён. Это первый и самый частый симптом.

Другие характерные проявления зависят от ситуации. При установке Windows на массив установщик не видит ни одного диска и требует драйвер. При уже существующем RAID после сброса BIOS система падает в ошибку загрузки (например, INACCESSIBLE_BOOT_DEVICE), потому что Windows загружалась через драйвер RAID, а контроллер внезапно перешёл в AHCI. В самой утилите RAID-конфигурации том может отображаться со статусом вроде Offline или вовсе отсутствовать.
