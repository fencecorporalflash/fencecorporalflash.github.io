Что такое UDL и как с его помощью проверить подключение к базе данных

Обновлено 24 сентября 2026 г.

UDL-файл позволяет за пару минут проверить, проходит ли подключение из Windows к SQL Server или другой базе данных, не запуская ни одной строчки кода и не устанавливая клиентские приложения. Если приложение выдаёт ошибку соединения с БД, а вы не понимаете, виноват сервер, сеть или строка подключения — именно файл .udl станет самым быстрым диагностическим инструментом.

Аббревиатура UDL расшифровывается как Universal Data Link — универсальная ссылка на данные. Это служебный файл Windows, внутри которого хранится строка подключения OLE DB в обычном текстовом виде. Операционная система «знает» этот формат: двойной щелчок по файлу открывает графический диалог настройки и тестирования соединения, встроенный в Windows.

Что представляет собой UDL-файл технически

По сути, UDL — это обычный текстовый файл с расширением .udl. Если открыть его в «Блокноте», внутри видны служебный заголовок и строка подключения, включающая провайдера данных, адрес сервера, имя базы и способ аутентификации. Именно эту строку затем можно скопировать в конфигурацию приложения.

Формат связан с технологией OLE DB и интерфейсом Data Link API, который давно входит в состав Windows. Поэтому для работы с UDL не нужно ничего устанавливать: диалог «Свойства связи с данными» доступен «из коробки» как в клиентских, так и в серверных версиях ОС.

Типичное содержимое файла выглядит примерно так:

[oledb]

; Everything after this line is an OLE DB initstring

Provider=SQLOLEDB.1;Data Source=SERVER\INSTANCE;Initial Catalog=MyDB;Integrated Security=SSPI

Конкретный набор параметров зависит от выбранного провайдера и версии драйвера, поэтому не стоит копировать строку вслепую — корректнее сформировать её через графический диалог на вашей машине.
