Команда set id ebd0a0a2-b9e5-4433-87c0-68b6b72699c7 в diskpart: назначение и применение

Обновлено 24 сентября 2026 г.
📋 Содержание

  • Когда требуется команда set id

Команда set id=ebd0a0a2-b9e5-4433-87c0-68b6b72699c7 в утилите diskpart назначает выбранному разделу GPT-диска тип «основной раздел данных» (Microsoft Basic Data), и именно этот GUID чаще всего требуется ввести вручную, когда раздел перестал отображаться в проводнике Windows или был ошибочно помечен как служебный. Ошибка в идентификаторе типа раздела приводит к тому, что система либо скрывает том, либо не может смонтировать его, хотя сами данные на диске остаются нетронутыми.

В этой статье разберём, что означает GUID ebd0a0a2-b9e5-4433-87c0-68b6b72699c7, в каких ситуациях требуется смена идентификатора раздела, как выполнить операцию через diskpart без потери информации и какие типовые ошибки допускают пользователи при работе с GPT-разметкой.

Что такое GUID раздела и зачем он нужен

На дисках с таблицей разделов GPT (GUID Partition Table) каждый раздел имеет два идентификатора: уникальный GUID самого раздела и GUID его типа. Именно тип сообщает операционной системе, как обращаться с разделом: монтировать ли его как обычный том, считать ли служебным (EFI, Recovery, Reserved) или игнорировать вовсе.

Идентификатор ebd0a0a2-b9e5-4433-87c0-68b6b72699c7 — это общеизвестный GUID типа Microsoft Basic Data, то есть обычного раздела данных, который Windows монтирует и отображает в проводнике с присвоением буквы диска. Если этот тип заменён на другой (например, на тип OEM-раздела или раздела восстановления), том исчезает из интерфейса, хотя физически файлы остаются на месте.

Команда set id в diskpart изменяет именно тип раздела, не затрагивая его содержимое. Это обратимая операция: GUID можно вернуть обратно в любой момент, если выбор раздела был выполнен корректно.

Когда требуется команда set id

На практике ручное изменение идентификатора типа раздела встречается в нескольких типовых сценариях. Важно понимать, что это не повседневная операция, а инструмент восстановления или тонкой настройки разметки.

  • 🔍 Раздел с данными пропал из проводника после манипуляций со сторонними менеджерами дисков или клонирования.
  • 🛠️ Требуется скрыть служебный раздел (например, раздел восстановления), сменив его тип, либо, наоборот, сделать его видимым.
  • 💾 После переноса системы на другой диск раздел получил неверный тип, и Windows отказывается его монтировать.
  • 🧩 Необходимо вернуть разделу стандартный тип Basic Data после ошибочного присвоения служебного GUID.
⚠️ Внимание: команда set id работает по-разному для GPT- и MBR-дисков. Для GPT указывается длинный GUID, для MBR — короткий шестнадцатеричный код. Применение GUID на MBR-диске или кода MBR на GPT-диске приведёт к ошибке. Заранее проверьте стиль разметки командой list disk (GPT-диски помечаются звёздочкой в соответствующем столбце).
