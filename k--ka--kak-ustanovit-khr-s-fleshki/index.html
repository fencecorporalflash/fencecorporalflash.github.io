Как установить Windows XP с флешки

Обновлено 24 сентября 2026 г.
📋 Содержание
  • Что понадобится перед началом
  • Создание загрузочной флешки

Чаще всего установка Windows XP с флешки останавливается на синем экране с кодом 0x0000007B сразу после загрузки файлов — это почти всегда признак того, что установщик не видит SATA-контроллер жёсткого диска без дополнительных драйверов. Если вы столкнулись именно с этим или просто хотите поставить XP на старый компьютер без дисковода, сначала проверьте режим работы контроллера в BIOS: переключение SATA Mode с AHCI на IDE (Compatible) решает большинство таких случаев ещё до начала установки.

Windows XP вышла задолго до того, как загрузка с USB стала стандартом, поэтому процедура имеет свои особенности: обычное копирование образа на флешку не сработает, а не все старые материнские платы умеют загружаться с USB вообще. Ниже разберём подготовку накопителя, настройку BIOS и типичные ошибки — шаг за шагом и без лишнего риска для данных.

Что понадобится перед началом

Перед записью образа убедитесь, что у вас есть всё необходимое. Список короткий, но каждый пункт влияет на результат.

  • 💾 USB-флешка объёмом от 1 ГБ — для XP этого достаточно, больший объём не помешает.
  • 💿 Образ Windows XP в формате ISO, желательно с интегрированным Service Pack 3.
  • 🖥️ Рабочий компьютер с Windows для создания загрузочного накопителя.
  • 🔑 Ключ продукта — 25-значный код, который установщик спросит в процессе.
  • 📦 Драйверы для старого железа: заранее скачайте сетевые драйверы, иначе после установки можно остаться без интернета.

Отдельно проверьте, поддерживает ли целевой компьютер загрузку с USB. На совсем старых платах (примерно до середины 2000-х) такой опции может не быть — тогда понадобится либо обновление BIOS, либо установка с CD-диска, либо загрузчик-посредник вроде Plop Boot Manager.

⚠️ Внимание: установка Windows XP полностью сотрёт данные на выбранном разделе диска. Перенесите нужные файлы с диска C на другой раздел или внешний носитель до начала процедуры.

Создание загрузочной флешки

Простое копирование файлов из ISO на флешку не сработает: установщик XP требует особой структуры загрузочного сектора. Наиболее предсказуемый результат даёт программа WinSetupFromUSB, созданная специально под установщики старых Windows. Есть и альтернатива — Rufus в старых версиях умел записывать XP, но совместимость зависит от конкретной сборки программы.

Порядок действий в WinSetupFromUSB выглядит так:

  • 1️⃣ Вставьте флешку и запустите программу от имени администратора.
  • 2️⃣ Выберите накопитель в верхнем списке и отметьте опцию автоформатирования (Auto format it with FBinst).
  • 3️⃣ Поставьте галочку напротив пункта Windows 2000/XP/2003 Setup и укажите путь к распакованному образу или смонтированному ISO.
  • 4️⃣ Нажмите GO и дождитесь окончания записи — процесс занимает несколько минут.
