PCI VEN_8086 DEV_041E SUBSYS_78171462 REV_06: что это за устройство и как установить драйвер

Обновлено 24 сентября 2026 г.

Код PCI VEN_8086 DEV_041E SUBSYS_78171462 REV_06 в Диспетчере устройств означает, что Windows видит встроенное графическое ядро Intel HD Graphics 4600 процессора поколения Haswell, установленного на материнской плате MSI, но не может подобрать для него драйвер. Чаще всего такая запись появляется в разделе «Другие устройства» с жёлтым восклицательным знаком и подписью «Видеоконтроллер (VGA-совместимый)» после чистой установки Windows.

Разберём идентификатор по частям. VEN_8086 — это код производителя Intel, DEV_041E — идентификатор графического ядра HD Graphics 4600 (GT2), SUBSYS_78171462 указывает на подсистему платы производителя Micro-Star International (MSI), а REV_06 — ревизию кремния. Знание этой расшифровки позволяет найти точный драйвер без сторонних «драйверпаков».

Как расшифровать идентификатор оборудования

Каждое PCI-устройство передаёт системе набор кодов, по которым Windows ищет драйвер в своей базе. Для просмотра полной строки откройте Диспетчер устройств, щёлкните по проблемному устройству правой кнопкой, выберите Свойства → Сведения → ИД оборудования. Верхняя строка и есть искомый идентификатор.

  • 🔹 VEN_8086 — Vendor ID, принадлежит корпорации Intel;
  • 🔹 DEV_041E — Device ID, соответствует Intel HD Graphics 4600;
  • 🔹 SUBSYS_78171462 — Subsystem ID: 1462 — это MSI, 7817 — код конкретной платы;
  • 🔹 REV_06 — аппаратная ревизия устройства.

Если Device ID отличается от 041E, не применяйте эту инструкцию вслепую: у Haswell существует несколько вариантов графики (0412, 0416, 0402 и другие), и драйвер подбирается по точному коду. Проверить принадлежность кода можно в публичных базах PCI ID, например через поисковый запрос по строке pci 8086 041e.
