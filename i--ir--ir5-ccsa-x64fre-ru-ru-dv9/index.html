ir5 ccsa x64fre ru-ru dv9: расшифровка метки сборки Windows 11

Обновлено 24 сентября 2026 г.
📋 Содержание

Строка ir5 ccsa x64fre ru-ru dv9 встречается в имени ISO-образа Windows 11 — это служебная метка сборки, по которой можно определить ветку разработки, архитектуру, язык и тип носителя ещё до установки системы. Пользователи чаще всего сталкиваются с ней при скачивании образа с торрентов или файлообменников, где имя файла выглядит примерно как 22000.1.co_release_IR5_ccsa_x64fre_ru-ru_DV9.iso.

Понимание этой строки помогает ответить на практические вопросы: какая именно версия системы внутри образа, подходит ли она под ваш компьютер и не подменён ли файл. Ниже разберём каждый фрагмент метки, покажем, как проверить подлинность образа, и разберём типичные риски установки таких сборок.

Расшифровка метки по фрагментам

Имена образов Windows формируются по внутреннему шаблону Microsoft: версия.ветка_архитектура-тип_язык_носитель. Каждый элемент несёт конкретную информацию о содержимом файла.

  • 🔢 22000.1 — номер сборки (build). Именно сборка 22000 стала первой публичной версией Windows 11.
  • 🌿 co_release — ветка разработки (cobalt release), из которой собран образ.
  • 🏷️ ir5 / ccsa — внутренние коды этапа и лаборатории сборки; для пользователя они важны лишь как часть идентификатора конкретного релиза.
  • 💻 x64fre — архитектура x64 (64-бит) и тип сборки fre (free, то есть релизная, без отладочной instrumentation).
  • 🌐 ru-ru — язык интерфейса: русский (Россия).
  • 💿 dv9 — тип носителя: образ в формате, ориентированном на DVD-9 / стандартную установку с USB или диска.

Ключевые для пользователя элементы — номер сборки, архитектура и язык. Остальные фрагменты нужны в основном для точной идентификации релиза при сравнении с официальными источниками.

Какой системе соответствует эта сборка

Метка с номером 22000 относится к первому стабильному поколению Windows 11. Соответственно, к образу применимы стандартные требования этой системы: 64-битный процессор, поддержка TPM 2.0, Secure Boot и достаточный объём оперативной памяти. Точный перечень требований стоит сверить с официальной документацией Microsoft, так как он может уточняться.

Важный нюанс: сборки с такими метками широко распространялись в период утечек и ранних релизов, поэтому файл с «правильным» именем вовсе не гарантирует, что внутри именно оригинальный образ. Имя файла может присвоить кто угодно.

💡

Метка ir5 ccsa x64fre ru-ru dv9 — это идентификатор сборки Windows 11 (build 22000, x64, русский язык). Само по себе имя файла не подтверждает подлинность образа.
