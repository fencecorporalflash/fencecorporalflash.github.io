Add Boot Option в BIOS ASUS: что писать и как добавить вариант загрузки

Обновлено 24 сентября 2026 г.
📋 Содержание

  • Что писать в полях: разбор каждого пункта

Когда в BIOS ноутбука ASUS пропадает пункт загрузки с диска, а в разделе Boot появляется строка Add New Boot Option, пользователь останавливается на главном вопросе — что именно вписывать в поля Path for boot option и Add boot option. Ошибка в этих полях приводит к тому, что созданная запись не запускает систему и ноутбук снова уходит в BIOS или показывает сообщение об отсутствии загрузочного устройства.

Эта опция встречается в интерфейсе ASUS UEFI BIOS на ноутбуках серий VivoBook, X-series, ROG и других. Она предназначена для ручного добавления загрузочной записи UEFI, когда автоматическое определение загрузчика не сработало — например, после переустановки Windows, замены SSD или сброса настроек. Ниже разберём, что означает каждое поле, какие значения туда вводить и в каких случаях ручное добавление вообще не требуется.

Что такое Add New Boot Option и когда она появляется

Пункт Add New Boot Option находится на вкладке Boot в BIOS ASUS и служит для ручной регистрации загрузочного файла в NVRAM материнской платы. В нормальном состоянии UEFI сам находит загрузчик операционной системы на диске и создаёт запись вида Windows Boot Manager. Если запись повреждена или удалена, система перестаёт грузиться, и пользователь идёт в BIOS искать причину.

Типичные ситуации, когда возникает необходимость в этой опции:

  • 🔧 после клонирования или замены диска загрузочная запись не перенеслась;
  • 💾 Windows установлена, но в списке загрузки отображается только сам диск без Windows Boot Manager;
  • ⚙️ был выполнен сброс BIOS к заводским настройкам, и записи загрузки очистились;
  • 🐧 нужно добавить загрузку альтернативной ОС, например Linux с собственным загрузчиком.

Стоит понимать: ручное добавление записи не восстановит повреждённый загрузчик на диске. Если файлы загрузки отсутствуют физически, никакие значения в полях не помогут — сначала нужно восстановить загрузчик средствами Windows.

Что писать в полях: разбор каждого пункта

После выбора Add New Boot Option BIOS предлагает заполнить несколько полей. Их названия могут немного отличаться в зависимости от версии прошивки, но смысл одинаков.

ПолеЧто означаетЧто писать
Select FilesystemВыбор раздела с загрузчикомРаздел EFI на диске с ОС (обычно определяется по пути PCI)
Path for boot optionПуть к загрузочному файлу\EFI\Microsoft\Boot\bootmgfw.efi для Windows
CreateПодтверждение путиНажать Enter, чтобы зафиксировать путь
Add boot option / Boot option nameИмя записи в меню загрузкиЛюбое понятное имя, например Windows 11

Поле Path for boot option — самое важное. Для Windows 10 и 11 в режиме UEFI загрузчик расположен по стандартному пути \EFI\Microsoft\Boot\bootmgfw.efi. Если вы устанавливали Linux, загрузчик обычно лежит в папке с именем дистрибутива, например \EFI\ubuntu\grubx64.efi — точный путь зависит от дистрибутива и способа установки.

💡

Для Windows в поле Path for boot option указывается путь \EFI\Microsoft\Boot\bootmgfw.efi — это стандартное расположение загрузчика UEFI.
