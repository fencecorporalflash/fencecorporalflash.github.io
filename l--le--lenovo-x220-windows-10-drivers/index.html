Драйверы Lenovo X220 для Windows 10: полное руководство по установке

Обновлено 24 сентября 2026 г.
📋 Содержание

  • Где брать драйверы для ThinkPad X220

Lenovo ThinkPad X220 выпускался под Windows 7, поэтому после установки Windows 10 в диспетчере устройств почти всегда остаются «неизвестные устройства» — чаще всего это ACPI-узел управления питанием, устройство на шине PCI Simple Communications Controller и датчик ускорения жёсткого диска. Windows 10 подтягивает часть драйверов автоматически через Центр обновления, но фирменные компоненты Lenovo — управление питанием, горячие клавиши, защиту диска — придётся ставить вручную.

Хорошая новость: платформа X220 (процессоры Intel второго поколения, чипсет QM67) полностью работоспособна под Windows 10. Встроенная графика Intel HD Graphics 3000, сетевые адаптеры, аудиоконтроллер и тачпад имеют рабочие драйверы — часть встроена в саму систему, часть доступна на сайте Lenovo или в каталоге обновлений Microsoft. Ниже разберём, что именно ставить и в каком порядке.

Что нужно проверить перед установкой драйверов

Сначала убедитесь, что установлена актуальная версия Windows 10 и все накопительные обновления: Параметры → Обновление и безопасность → Центр обновления Windows → Проверить наличие обновлений. Система сама подтянет базовые драйверы для чипсета, видео и сети, и это закроет большую часть задач без ручной работы.

Далее откройте Диспетчер устройств (правый клик по кнопке «Пуск» → «Диспетчер устройств») и выпишите все позиции с жёлтым восклицательным знаком. Для каждой полезно посмотреть ИД оборудования: правый клик по устройству → «Свойства» → вкладка «Сведения» → свойство «ИД оборудования». Значения вида ACPI\LEN0068 или PCI\VEN_8086&DEV_... позволяют точно определить, какой драйвер требуется.

  • 🔎 Сфотографируйте или запишите список проблемных устройств до начала установки — так проще контролировать результат.
  • 🌐 Проверьте, работает ли сеть: если Wi-Fi не определился, временно подключите ноутбук кабелем Ethernet — контроллер Intel 82579LM обычно определяется системой сразу.
  • 💾 Создайте точку восстановления системы перед установкой пакетов драйверов — это обратимая подстраховка.

Где брать драйверы для ThinkPad X220

Основной источник — официальный сайт поддержки Lenovo: введите в поиске «X220» или серийный номер машины, выберите операционную систему. Для X220 официальные пакеты выпускались под Windows 7 и Windows 8, но большинство из них нормально устанавливаются и на Windows 10 — либо напрямую, либо в режиме совместимости.

Второй источник — каталог Центра обновления Майкрософт (Microsoft Update Catalog), где по ИД оборудования можно найти подписанные драйверы для конкретных устройств. Третий вариант — сайт Intel: там доступны драйверы чипсета (INF Update) и графики HD Graphics 3000. Избегайте сторонних «сборников драйверов» и программ-автоустановщиков — они часто ставят неподходящие версии или нежелательное ПО.

⚠️ Внимание: Lenovo прекратила выпуск новых драйверов для X220, поэтому последние доступные версии на сайте — финальные. Если пакет отказывается устанавливаться под Windows 10, попробуйте запустить установщик в режиме совместимости с Windows 7 (правый клик по файлу → «Свойства» → «Совместимость»).

Порядок установки драйверов

Последовательность имеет значение: сначала ставятся системные компоненты, затем периферия. Нарушение порядка редко приводит к сбоям, но может вызвать лишние «неизвестные устройства» в диспетчере.

  1. Обновления Windows 10 (чипсет, сеть, базовое видео подтянутся автоматически).
  2. Intel Chipset INF Utility — обновляет описания устройств чипсета в системе.
  3. Драйвер графики Intel HD Graphics 3000.
  4. Intel Management Engine Interface (AMT) — закрывает PCI Simple Communications Controller.
  5. Аудиодрайвер Conexant.
  6. Сетевые драйверы: Ethernet Intel, Wi-Fi (Intel Centrino), Bluetooth.
  7. Фирменные компоненты Lenovo: Hotkey Features Integration, Power Management Driver, Active Protection System, драйвер тачпада/TrackPoint (UltraNav), драйвер считывателя отпечатков при наличии.
