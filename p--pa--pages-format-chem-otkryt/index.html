Формат Pages: чем открыть файл .pages на Windows, Mac и онлайн

Обновлено 24 сентября 2026 г.
📋 Содержание

Файл с расширением .pages, присланный по почте или в мессенджере, не открывается двойным кликом на компьютере с Windows — система просто не знает, какой программой его обработать. Это документ, созданный в приложении Pages — текстовом редакторе из офисного пакета Apple iWork, который работает только на macOS и iOS.

Хорошая новость: открыть такой файл можно и без техники Apple. Существует несколько рабочих способов — от простого «трюка с архиватором» до полноценной конвертации в привычные форматы DOCX и PDF. Ниже разберём все варианты пошагово и поможем выбрать подходящий под вашу ситуацию.

Что представляет собой формат Pages

Pages — это фирменный формат текстовых документов Apple, аналог Microsoft Word. Файл .pages по сути является контейнером: внутри него упакованы XML-данные с текстом и структурой документа, встроенные изображения, а также превью документа в виде PDF или JPEG.

Именно эта особенность структуры позволяет «заглянуть внутрь» файла даже без специальных программ. Старые версии формата содержат отдельный файл предпросмотра, который можно извлечь обычным архиватором — об этом подробнее в следующем разделе.

Формат не поддерживается напрямую ни одной программой вне экосистемы Apple. Microsoft Word не умеет открывать .pages нативно — попытка открыть файл через Word приведёт к ошибке или отображению служебных данных вместо текста.

Способ 1: открыть через iCloud в браузере

Самый корректный способ просмотреть документ без потери форматирования — воспользоваться веб-версией Pages на сайте iCloud. Для этого понадобится учётная запись Apple ID, которую можно создать бесплатно даже без устройств Apple.

Порядок действий выглядит так:

  • 🌐 Откройте сайт icloud.com и войдите с Apple ID
  • 📄 Перейдите в раздел Pages среди доступных приложений
  • ⬆️ Загрузите файл через кнопку загрузки или просто перетащите его в окно браузера
  • 👁️ Откройте документ для просмотра и редактирования прямо в браузере
  • 💾 При необходимости скачайте копию через меню: документ можно выгрузить в форматах Word (.docx), PDF, EPUB или RTF

Этот метод сохраняет исходную вёрстку, шрифты и изображения максимально точно, поскольку обработкой занимается «родной» редактор Apple. Если документ важен и нужно не только прочитать его, но и внести правки — начинайте именно с iCloud.

💡

iCloud — единственный способ открыть .pages на Windows с полным сохранением форматирования, поскольку используется оригинальный редактор Apple.
