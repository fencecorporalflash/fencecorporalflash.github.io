Linux на Raspberry Pi 3: установка, настройка и выбор дистрибутива

Обновлено 24 сентября 2026 г.

Если Raspberry Pi 3 после установки Linux загружается дольше минуты, показывает радужный экран или зависает на чёрном экране с мигающим курсором — в подавляющем большинстве случаев виновата не плата, а карта памяти или некорректно записанный образ. Модель Raspberry Pi 3 (включая версии B и B+) построена на четырёхъядерном процессоре ARM Cortex-A53 с 1 ГБ оперативной памяти, и этого достаточно для полноценной работы большинства Linux-дистрибутивов — при условии правильной подготовки носителя.

В этой статье разберём, какие дистрибутивы Linux реально работоспособны на третьей «малине», как записать образ без ошибок, что настроить сразу после первого запуска и как диагностировать типовые проблемы: от недостаточного питания до повреждённой файловой системы.

Какие дистрибутивы Linux подходят для Raspberry Pi 3

Основной кандидат — Raspberry Pi OS (бывший Raspbian), официальная система от Raspberry Pi Foundation. Она собрана на базе Debian, содержит все необходимые драйверы и оптимизирована под ограниченные ресурсы платы. Существует в трёх вариантах: с графическим окружением, Lite (только консоль) и промежуточная версия без рекомендованного ПО.

Помимо официальной системы, на Raspberry Pi 3 стабильно работают и другие сборки. Выбор зависит от задачи: медиацентр, сервер, ретроконсоль или десктоп — для каждого сценария есть свой дистрибутив.

  • 🐧 Raspberry Pi OS Lite — минимальная система без графики, оптимальна для серверов и headless-проектов.
  • 🖥️ Ubuntu Server / Ubuntu MATE — привычная экосистема Ubuntu, пакеты apt, но требовательнее к памяти.
  • 📺 LibreELEC / OSMC — специализированные сборки на базе Kodi для медиацентра.
  • 🎮 RetroPie — дистрибутив для ретро-эмуляции, ставится поверх Raspberry Pi OS или отдельным образом.
  • 🛡️ DietPi — ультралёгкая система с удобным меню установки серверного ПО.

Для 1 ГБ ОЗУ принципиально важно: чем меньше фоновых служб и графики, тем стабильнее работа. Если планируется сервер, умный дом или сетевые эксперименты — берите Lite-версии и управляйте платой по SSH.
