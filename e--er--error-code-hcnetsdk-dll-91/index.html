Ошибка HCNetSDK.dll код 91: причины и решение

Обновлено 24 сентября 2026 г.
📋 Содержание
  • Что такое HCNetSDK.dll и почему возникают коды ошибок
  • Типичные причины появления кода 91

Ошибка error code hcnetsdk dll 91 появляется в программах видеонаблюдения, работающих через библиотеку HCNetSDK.dll от Hikvision, — чаще всего в момент подключения к регистратору, попытки просмотра архива или запуска потока с камеры. Сообщение обычно выглядит как «Play failed, error code: 91» или всплывает в логе iVMS-4200, сторонних VMS и самописных приложений, использующих этот SDK.

Код 91 возвращается самой библиотекой HCNetSDK, а не операционной системой. Это значит, что Windows и драйверы здесь, как правило, ни при чём: сбой происходит на уровне взаимодействия клиентского ПО с устройством — при инициализации сессии, запросе потока или вызове функции, которую устройство в текущем состоянии не может выполнить. Точная расшифровка кода зависит от версии SDK, поэтому диагностику стоит вести по симптомам и контексту появления ошибки.

Ниже разберём типичные сценарии появления сбоя, безопасные проверки и порядок действий, который помогает локализовать проблему без риска для настроек системы видеонаблюдения.

Что такое HCNetSDK.dll и почему возникают коды ошибок

HCNetSDK.dll — это динамическая библиотека из состава SDK Hikvision, через которую клиентские приложения обращаются к камерам и регистраторам: логинятся, получают видеопоток, управляют PTZ, скачивают архив. Любой вызов функции SDK возвращает числовой код: ноль означает успех, остальные значения — типы ошибок.

Коды ошибок документируются производителем в руководстве к конкретной версии SDK, и их расшифровка может отличаться между версиями. Поэтому первое, что стоит сделать при повторяющемся коде 91, — свериться с документацией именно той версии SDK, которая используется вашим ПО. Универсальная таблица «на все случаи» здесь ненадёжна.

⚠️ Внимание: не заменяйте файл HCNetSDK.dll вручную библиотекой, скачанной со сторонних сайтов «DLL-библиотек». Несовпадение версий SDK и остальных компонентов ПО часто порождает новые ошибки, а файлы из непроверенных источников могут содержать вредоносный код.

Типичные причины появления кода 91

По опыту диагностики систем на базе Hikvision сбой с кодом из этой группы чаще всего связан с одной из следующих причин. Ни одну из них нельзя считать установленным фактом без проверки — это направления диагностики.

  • 🔌 Проблема с сетевым соединением между ПК и устройством: нестабильный канал, потери пакетов, блокировка портов брандмауэром.
  • 🔑 Ошибка авторизации: неверный логин/пароль, заблокированная учётная запись, исчерпан лимит одновременных подключений к устройству.
  • 📦 Несовместимость версий: устаревшая версия SDK в клиентском ПО и новая прошивка устройства (или наоборот).
  • 🎛️ Неподдерживаемая операция: вызов функции, которую конкретная модель или текущая прошивка не поддерживает (например, запрос потока в недоступном формате).
  • 🧩 Повреждённые или конфликтующие файлы SDK в папке программы после неудачного обновления.
