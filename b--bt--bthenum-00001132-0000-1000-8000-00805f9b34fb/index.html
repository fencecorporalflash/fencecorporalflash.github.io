BTHENUM 00001132-0000-1000-8000-00805f9b34fb: расшифровка идентификатора и исправление ошибки драйвера

Обновлено 24 сентября 2026 г.
📋 Содержание
  • Что скрывается за идентификатором 00001132
  • Где именно можно увидеть эту строку

Идентификатор BTHENUM\{00001132-0000-1000-8000-00805f9b34fb} появляется в диспетчере устройств Windows, когда система обнаруживает у сопряжённого Bluetooth-устройства сервис Message Access Server — но не может подобрать для него подходящий драйвер. Запись с таким путём экземпляра устройства чаще всего видна в свойствах проблемного компонента с жёлтым восклицательным знаком либо в журнале событий после сопряжения телефона, смарт-часов или автомобильной гарнитуры с компьютером.

Код 00001132 — это 16-битный UUID из официального реестра Bluetooth SIG, где он закреплён за профилем доступа к сообщениям (Message Access Profile, MAP), а точнее — за ролью сервера сообщений. Оставшаяся часть строки 0000-1000-8000-00805f9b34fb — стандартный суффикс базового UUID Bluetooth, одинаковый для всех сервисов спецификации. Сам префикс BTHENUM указывает, что устройство было создано перечислителем Bluetooth-шины Windows, а не физическим адаптером. Ниже разберём, откуда берётся эта запись, когда она является проблемой и как безопасно её устранить.

Что скрывается за идентификатором 00001132

Профиль Message Access Profile позволяет одному устройству читать SMS, уведомления и другие сообщения с другого устройства. Типичный сценарий: автомобильная магнитола или смарт-часы запрашивают у смартфона доступ к сообщениям, чтобы выводить их на экран. Когда вы сопрягаете телефон с ПК, Windows видит, что телефон публикует сервис MAP, и создаёт для него виртуальное устройство через перечислитель BTHENUM.

Поскольку Windows не имеет встроенного полноценного клиентского драйвера для роли MAP-сервера, такое устройство часто отображается как неизвестное или с ошибкой «драйверы не установлены». Это не неисправность Bluetooth-адаптера и не вирус — это следствие того, что профиль обнаружен, но системному ПО для его обслуживания нет или оно не установлено.

  • 🔹 BTHENUM — системный перечислитель Windows, создающий программные устройства для каждого Bluetooth-сервиса.
  • 🔹 00001132 — UUID сервиса Message Access Server по классификации Bluetooth SIG.
  • 🔹 00805f9b34fb — завершающая часть базового UUID, общая для всех стандартных профилей Bluetooth.
  • 🔹 Запись появляется после сопряжения со смартфоном, часами, планшетом или автомобильной системой.

Где именно можно увидеть эту строку

Чаще всего пользователь замечает идентификатор в диспетчере устройств: откройте свойства проблемного устройства, перейдите на вкладку Сведения и в выпадающем списке выберите Путь к экземпляру устройства или ИД оборудования. Там и будет строка вида BTHENUM\{00001132-0000-1000-8000-00805f9b34fb} с дополнительными суффиксами, указывающими на адрес конкретного сопряжённого устройства.

Вторая типичная точка обнаружения — журнал событий Windows. Ошибки с кодом, связанным с установкой драйвера, фиксируются в разделе Просмотр событий → Журналы Windows → Система с источником Kernel-PnP или User Device Registration. Третий вариант — вывод команды в командной строке:

pnputil /enum-devices /problem

Эта команда покажет все устройства с проблемами, включая виртуальные Bluetooth-эндпоинты, что удобно для быстрой диагностики без открытия графического интерфейса.
