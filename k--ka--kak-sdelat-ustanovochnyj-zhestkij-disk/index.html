Как сделать установочный жесткий диск

Обновлено 24 сентября 2026 г.

Если BIOS компьютера не видит загрузочную флешку, а установить Windows нужно именно с жесткого диска — задача решается через запись установочного образа на внешний HDD или SSD, подключенный по USB. Такой накопитель работает аналогично загрузочной флешке: с него запускается установщик системы, при этом остается возможность хранить на диске и обычные файлы. Ниже разберем подготовку диска, способы записи образа и типичные ошибки, из-за которых установочный диск не определяется при загрузке.

Метод подходит для внешних жестких дисков и SSD в боксе, а также для второго внутреннего накопителя, если загрузку с него поддерживает материнская плата. Перед началом учтите: часть способов полностью стирает данные с диска, поэтому важные файлы заранее скопируйте в другое место.

Что понадобится для создания установочного диска

Для работы потребуется сам жесткий диск с достаточным объемом свободного места, ISO-образ нужной версии Windows и программа для записи. Образ системы загружайте только с официального сайта Microsoft — через Media Creation Tool или страницу скачивания ISO. Сторонние сборки могут содержать измененные установщики, и их поведение никто не гарантирует.

Из программ чаще всего используют Rufus, Ventoy или WinSetupFromUSB. Они бесплатны и работают без установки. Вам также понадобится компьютер с Windows, на котором будет выполняться запись, и свободный порт USB — желательно напрямую на материнской плате, без хабов.

  • 💾 Внешний HDD или SSD с запасом места под образ и файлы
  • 📀 Официальный ISO-образ Windows нужной версии
  • 🛠️ Утилита для записи: Rufus, Ventoy или аналог
  • 🔌 Исправный USB-кабель и порт без нестабильного контакта

Подготовка жесткого диска к записи

Прежде чем записывать образ, проверьте состояние диска. Откройте «Управление дисками» через контекстное меню кнопки «Пуск» и убедитесь, что накопитель определяется корректно, без ошибок файловой системы. Если диск старый, не лишним будет выполнить проверку командой chkdsk в командной строке.

Далее определитесь со схемой разделов. Для современных компьютеров с UEFI нужна разметка GPT, для старых машин с legacy BIOS — MBR. Узнать режим своего ПК можно в сведениях о системе: откройте msinfo32 и посмотрите строку «Режим BIOS». Несовпадение разметки и режима загрузки — одна из самых частых причин, почему установочный диск не стартует.

⚠️ Внимание: преобразование диска между MBR и GPT штатными средствами Windows удаляет все разделы и данные. Если на диске есть нужная информация, сначала сделайте резервную копию.

Запись образа через Rufus

Запустите Rufus от имени администратора. В поле «Устройство» выберите ваш жесткий диск — если он не отображается, включите в настройках показ USB-дисков большого объема (опция «Показать расширенные параметры» → «Показывать внешние USB-диски», в актуальных версиях пункт может называться иначе). Затем нажмите «Выбрать» и укажите скачанный ISO-файл.

В поле «Схема раздела» выставьте GPT для UEFI или MBR для legacy-загрузки, файловую систему оставьте NTFS — программа сама решит вопрос с файлами установщика размером больше 4 ГБ. После нажатия «Старт» подтвердите предупреждение об удалении данных и дождитесь окончания записи. По завершении безопасно извлеките диск через значок в трее.
