User Mode Block Device в диспетчере устройств: разбираемся с виртуальным устройством

Обновлено 24 сентября 2026 г.

Запись User Mode Block Device в диспетчере устройств Windows появляется после установки программ, создающих виртуальные диски: эмуляторов образов, утилит для монтирования ISO, ПО для шифрования томов и некоторых игровых античит-компонентов. Жёлтый восклицательный знак рядом с этой строкой или её внезапное появление — типичный повод разобраться, какой именно драйвер стоит за устройством и нужен ли он системе.

Сам по себе такой элемент не является вирусом или признаком аппаратной неисправности. Это виртуальное блочное устройство, работающее в пользовательском режиме: вместо того чтобы полностью выполняться в ядре Windows, часть логики драйвера запущена как обычный пользовательский процесс. Ниже рассмотрим, как определить источник записи, когда её можно удалить и как это сделать без последствий.

Что означает User Mode Block Device

Термин складывается из двух частей. Block device — блочное устройство, то есть накопитель, с которым система работает блоками данных: жёсткий диск, SSD, флешка, виртуальный том. User mode указывает, что обработка запросов частично выполняется в пользовательском режиме, а не только в режиме ядра. Такой подход упрощает разработку драйверов и снижает риск «синих экранов» при ошибках в коде.

В диспетчере устройств подобные записи обычно находятся в разделах «Дисковые устройства», «Контроллеры запоминающих устройств» или в ветке виртуальных устройств конкретной программы. Точное расположение зависит от того, как разработчик зарегистрировал свой драйвер в системе.
