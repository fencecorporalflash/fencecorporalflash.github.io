Диск в macOS: полное руководство по работе с накопителями

Обновлено 24 сентября 2026 г.
📋 Содержание
  • Файловые системы и форматы диска в macOS
  • Дисковая утилита: основной инструмент

Дисковая утилита в macOS выдаёт ошибку «Не удалось стереть диск» при попытке переформатировать накопитель — с этой ситуации обычно и начинается знакомство с управлением дисками на Mac. Причина чаще всего в том, что диск смонтирован и используется системой, либо выбрана несовместимая схема разделов. Ниже разберём, как устроена работа с накопителями в macOS, какие инструменты встроены в систему и как безопасно выполнить базовые операции.

Операционная система Apple работает с дисками через собственные файловые системы — APFS и устаревшую Mac OS Extended (HFS+). Понимание различий между форматами и правильный выбор схемы разделов избавят от потери данных и ошибок при установке системы или подключении внешних накопителей.

Файловые системы и форматы диска в macOS

Начиная с macOS High Sierra, основной файловой системой стала APFS (Apple File System). Она оптимизирована под SSD-накопители, поддерживает моментальные снимки (snapshots), шифрование и гибкое распределение пространства между томами внутри одного контейнера. Для механических жёстких дисков и старых систем может использоваться Mac OS Extended (журналируемая).

Для внешних накопителей, которыми планируется пользоваться и на Windows, подходят кроссплатформенные форматы. Вам нужно учитывать ограничения каждого из них:

  • 💾 exFAT — читается и записывается на Mac и Windows, подходит для больших файлов.
  • 📁 FAT32 — максимальная совместимость, но ограничение на размер одного файла в 4 ГБ.
  • 🍎 APFS — только для Mac и современных версий macOS, оптимальна для SSD.
  • 🔧 Mac OS Extended — для старых Mac и механических HDD, а также для резервных копий Time Machine на старых системах.
⚠️ Внимание: форматирование диска уничтожает все данные на нём. Перед сменой файловой системы обязательно скопируйте важные файлы на другой носитель или в облачное хранилище.

Дисковая утилита: основной инструмент

Встроенное приложение Дисковая утилита находится в папке Программы → Утилиты. Также его можно открыть через поиск Spotlight, введя название программы. Утилита позволяет просматривать все подключённые накопители, форматировать их, создавать и удалять разделы, проверять диски на ошибки.

Важная деталь интерфейса: по умолчанию Дисковая утилита показывает только тома, а не физические устройства. Чтобы увидеть структуру диска целиком, включите в меню Вид → Показать все устройства. Без этого режима некоторые операции, например смена схемы разделов, будут недоступны.

💡

Если внешний диск не отображается в боковом меню Finder, проверьте настройки: Finder → Настройки → Общие → отметьте пункт «Внешние диски».
