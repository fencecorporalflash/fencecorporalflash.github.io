EFI PXE 0 for IPv6 Boot Failed: причины ошибки и пошаговое решение

Обновлено 24 сентября 2026 г.

Ошибка EFI PXE 0 for IPv6 boot failed появляется на экране ноутбука, когда прошивка UEFI не нашла загрузочную операционную систему на диске и перешла к последнему варианту из списка — загрузке по сети через протокол PXE с использованием IPv6. Само сообщение не является поломкой: это симптом того, что компьютер перепробовал все доступные устройства загрузки и не смог стартовать ни с одного из них.

Чаще всего проблема встречается на ноутбуках Lenovo, HP, Dell и Acer, но механизм одинаков для любого устройства с UEFI. Важно понимать: сетевая загрузка (PXE boot) сама по себе не сломана — она просто оказалась в приоритете выше, чем реальный загрузчик Windows, либо диск действительно перестал определяться. Дальнейшая диагностика строится именно на разделении этих двух сценариев.

Что означает сообщение EFI PXE 0 for IPv6

Аббревиатура PXE (Preboot Execution Environment) обозначает технологию загрузки компьютера по сети без локального диска. Она используется в корпоративных сетях для развёртывания систем на множестве машин. На домашнем ноутбуке PXE обычно не нужен, но пункт сетевой загрузки присутствует в списке Boot практически у всех производителей.

Когда UEFI доходит до строки EFI PXE 0 for IPv6, это значит, что все предыдущие варианты загрузки — SSD, HDD, USB — завершились неудачей. Прошивка пытается получить загрузчик с сетевого сервера, не находит его (дома его просто не существует) и выдаёт сообщение boot failed. Иногда рядом присутствует похожая строка EFI PXE 0 for IPv4 — логика та же, отличается только версия сетевого протокола.

Таким образом, реальный вопрос звучит иначе: почему ноутбук не загрузился с диска? Причины делятся на программные (сбитый порядок загрузки, повреждённый загрузчик Windows, режим Secure Boot) и аппаратные (отошедший или вышедший из строя накопитель).

💡

Сообщение EFI PXE 0 for IPv6 boot failed — это не ошибка сетевой загрузки, а признак того, что UEFI не смог запустить систему с локального диска и дошёл до последнего пункта в списке загрузки.
